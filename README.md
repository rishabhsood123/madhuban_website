# Madhuban Homestay

A premium, fully responsive website for **Madhuban Homestay**, located in the scenic Fozal Valley of Kullu, Himachal Pradesh. This website showcases the homestay's accommodations, facilities, house rules, and features an interactive monthly gallery exhibiting the valley's beauty across all four seasons.

## Features

- **Elegant Aesthetics**: A custom modern design using natural, harmonious colors (forest greens, warm earth tones) and high-quality typography.
- **Dynamic 12-Month Gallery**: A monthly gallery section with stunning AI-generated placeholder images that allow guests to explore "Life at Madhuban" from January to December (Winter, Spring, Monsoon, Autumn).
- **Responsive Layout**: Tailored to look beautiful on all screen sizes, from mobile phones (e.g., iPhone 13) to wide laptop dimensions.
- **Accommodation & Facilities**: Interactive bento-grid showcase of rooms (Orchard Room, Valley Room, Attic Stay) and standard amenities.
- **Interactive Lightbox**: Fully custom-built keyboard-accessible photo viewer for high-resolution images.

## Technology Stack

- **Framework**: React 18 + Vite (for lightning-fast HMR and building)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (modern CSS grid, flexbox, custom variables, and responsive design systems)
- **Icons**: Material Symbols (Google Fonts)

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/rishabhsood123/madhuban_website.git
   cd madhuban_website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build the application for production:
   ```bash
   npm run build
   ```
